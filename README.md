# Mila

Asistente personal de Luzmila (PWA). Se publica con GitHub Pages: https://a20255004-hash.github.io/LUZMILA/

- `index.html`, `runtime.js`, `sw.js`, `manifest.json`, `icon.svg`: la app publicada (archivos completos).
- `src/`: el código fuente por módulos; `index.html` se arma uniendo `src/shell.html`, `src/styles.css` y `src/js/*.js`.

Los datos personales no están aquí: viven en el navegador de cada dispositivo y en una copia privada en Google Drive.
